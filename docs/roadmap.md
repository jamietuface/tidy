# Tidy — Roadmap

## v1.0 — Launch (Current)
- [x] Project scaffold (Flutter + Riverpod + go_router)
- [x] Apple design system (AppColors, AppTheme)
- [x] Onboarding (3 screens)
- [x] Home screen (Photos + Apps tabs)
- [x] Swipe screen UI (keep/delete)
- [x] AI groups UI (Blurry, Screenshots, Duplicates, Old)
- [x] Subscriptions screen (app spend tracker)
- [x] Paywall (monthly + annual)
- [ ] Photo library permission + real photo loading
- [ ] Actual swipe gesture physics
- [ ] AI photo grouping (on-device Core ML)
- [ ] App usage data (Screen Time API)
- [ ] StoreKit 2 subscription handling
- [ ] iCloud sync for deleted photo history
- [ ] App Store submission

## v1.1 — Polish (Month 2)
- [ ] Haptic feedback on swipe commit
- [ ] "Results" screen after cleaning session (X photos deleted, Y MB freed)
- [ ] Share results card (viral loop)
- [ ] Undo last swipe
- [ ] Swipe session streaks / gamification
- [ ] Widget: storage freed today

## v1.2 — AI (Month 3)
- [ ] On-device ML model for blur detection
- [ ] Duplicate detection (perceptual hash)
- [ ] Face grouping (group selfies, group people)
- [ ] Location grouping (group by trip/place)
- [ ] Smart date grouping (group by event)

## v2.0 — Android + Growth (Month 4–6)
- [ ] Android launch (Flutter cross-platform)
- [ ] Referral programme (1 month free per referral)
- [ ] Family sharing (shared Tidy Pro)
- [ ] Tidy for iPad (larger swipe cards, split view)

## v3.0 — Platform (Year 2)
- [ ] Tidy for Mac (macOS app, Photos library)
- [ ] Tidy API (for 3rd party storage integrations)
- [ ] B2B white-label offering
- [ ] Tidy Teams (family/shared accounts)

---

## Prioritisation Framework
Features are prioritised by: **Revenue impact × User delight ÷ Build complexity**

High priority = high revenue + high delight + low complexity (e.g. share results card)
Low priority = low revenue + low delight + high complexity (e.g. Tidy API)
