# Tidy Logo Reference Assets

These are cropped from the approved generated Tidy brand reference boards.

Use these as high-fidelity raster references/assets for the in-app logo if a CustomPainter cannot match the design closely enough.

Suggested app paths:
- assets/brand/tidy_logo_mark_light.png
- assets/brand/tidy_logo_mark_dark.png
- assets/brand/tidy_brand_lockup_light.png
- assets/brand/tidy_brand_lockup_dark.png

Important:
- Light theme should use tidy_logo_mark_light.png.
- Dark theme should use tidy_logo_mark_dark.png.
- Use the user's Tidy theme setting: Use System / Light / Dark.
- The dashboard must also switch light/dark; not just Settings.
